# Contributing

Thanks for helping improve the IAM Glossary!

## How to contribute
1. Open an issue describing the term, correction, or source-link update.
2. For a change, create a branch and edit `GLOSSARY.md`.
3. Keep definitions concise, neutral, and written in your own words.
4. Link to primary sources where possible: NIST, RFC Editor/IETF, W3C, OASIS, or the relevant standards body.
5. Check that links work and that a cited standard has not been superseded.
6. Submit a pull request explaining the change.

## Entry format
Use the existing table format:

`| **Term** | One-sentence definition. | [Source](https://example.org/standard) |`

Please avoid copying long passages from standards. The glossary is an educational index, not a replacement for the source documents.
