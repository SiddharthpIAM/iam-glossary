# IAM Glossary

A curated, beginner-friendly reference of **153 Identity and Access Management (IAM) terms**, with one-line definitions and links to relevant NIST guidance, IETF RFCs, and industry specifications.

## What you'll find

- Identity fundamentals and lifecycle
- Authentication, MFA, passkeys, and sessions
- Authorization and access-control models
- SSO, federation, OAuth 2.0, OIDC, SAML, JWT, and SCIM
- Provisioning, governance, privileged access, and zero trust
- Cryptography and supporting security concepts

## Start here

Read **[GLOSSARY.md](GLOSSARY.md)** for the complete alphabet-friendly, category-based glossary and references.

## Sources and accuracy

Definitions are concise paraphrases for learning. Use linked primary standards for normative requirements. Standards evolve, so verify publication status and revision dates before relying on a reference for implementation or compliance.
